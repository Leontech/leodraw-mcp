# Changelog

## 0.2.0 – 2026-11-20

Faster work, better orientation and production tools for laser / plotter cutting.

- `batch`: several tool calls in one request, undone as a single step.
- `copy_shapes`: copy or move shapes to another page (keeps the position, optional rotation).
- `fill_template`: fill `{{placeholders}}` in texts from a values map (labels, nameplates).
- `shape_boolean`: weld, intersect, trim, simplify.
- `offset_path`: offset (contour) curve inside or outside – e.g. a cutting line around a sticker.
- `create_qr_code`: QR code as one vector curve, generated by LeoDraw (levels L/M/Q/H, size in mm).
- `trace_bitmap`: vectorize bitmaps with PowerTRACE.
- `preflight`: lists texts not converted to curves, thick outlines, open curves, tiny shapes, shapes outside
  the page, low-resolution bitmaps, duplicates, locked shapes, hidden layers with content.
- `prepare_for_cutting`: curves + hairline outline + no fill in one step.
- `list_shapes` / `find_shapes`: `compact` one-line-per-shape output; `find_shapes` searches a region.
- `render_preview`: preview of a region (`x, y, w, h`).
- Preview and export leave out hidden layers (`include_hidden` for the old behaviour).
- `transform_shapes`: move along one axis only. `create_text`: `box: "line"` positions by the text line box.
- `replace_text` on given shapes (`ids`); `group` with `into` adds shapes to an existing group.
- `import_file` from a `url` or `data_base64`.
- Modifying tools activate the target page first (CorelDRAW silently ignores grouping on an inactive page).
- A timeout tells whether CorelDRAW is not responding.
- Setup window: two-column layout without scrolling, shows the Claude Desktop config file
  ("Show file") and how to find it in Claude (Settings → Developer → Edit Config).

## 0.1.0 – 2026-11-20

Phase 1: everyday work with a document without touching the mouse – about 50 new tools.

- Documents: `list_documents`, `activate_document`, `new_document`, `open_document`, `save_document`,
  `save_document_as` (also older CDR versions), `close_document` (refuses to drop unsaved changes unless asked).
- Pages: `list_pages`, `add_pages`, `delete_page`, `set_page`, `activate_page`.
- Layers: `list_layers`, `create_layer`, `delete_layer`, `set_layer`, `set_active_layer`, `move_to_layer`.
- Inspect: `get_shape`, `find_shapes`, `get_path` (shape geometry as SVG path data), `select_shapes`,
  `clear_selection`, `set_shape_props`, `list_fonts`.
- Draw: `create_ellipse` (arcs, pies), `create_polygon` (stars), `create_line`, `create_path` (SVG path data
  incl. arcs and quadratic curves → native curve), `import_file`, `import_svg`.
- Text: `create_text`, `create_paragraph_text`, `set_text`, `set_text_style` (also character ranges), `replace_text`.
- Transform: `transform_shapes`, `align_shapes`, `distribute_shapes`, `duplicate_shapes`, `order_shapes`, `delete_shapes`.
- Style: `set_fill` (uniform colour, gradients), `set_outline` (width, hairline, caps, joins …).
- Shaping: `group`, `ungroup`, `combine`, `break_apart`, `convert_to_curves`.
- `export`: PDF, SVG, DXF, DWG, EPS, AI, PLT, EMF, PNG, JPG, TIFF, WebP … (page, all pages, selection or shapes);
  existing files are kept unless `overwrite` is set.
- Positions can use an `anchor` (top-left, center, …); colours accept all CSS colour names.
- `call_tool` reaches tools missing from a client's cached tool list (after `server_reload`).
- `api_describe` describes any interface by name (`type`) and several enumerations at once.
- Timeouts report which CorelDRAW call is still running.
- Connects to CorelDRAW also while it shows its welcome screen.
- Releases also contain `leodraw-mcp.mcpb` – an MCP Bundle for one-click installation in Claude Desktop.

## 0.0.15 – 2026-11-20

- Shapes are found by id by walking the layers and groups (CorelDRAW's FindShape cannot search
  "any name" in late-bound calls) – fixes `render_preview` with `ids`.

## 0.0.13 – 2026-11-20

- `render_preview` of a page renders the whole page (export area = page bounding box), not only the
  extent of its objects.
- `api_describe` hides the generic IUnknown / IDispatch methods.

## 0.0.12 – 2026-11-20

- Fixed `render_preview` with CorelDRAW 2026: late-bound calls must pass all parameters, optional ones
  included (optional object parameters as Nothing).
- New `api_describe` tool: method signatures and enumeration values read from the type library of the
  installed CorelDRAW – helps when the API differs between versions.
- New `server_reload` tool: the exe now runs as a small supervisor with the server as a child process,
  so an updated `leodraw-mcp.exe` is loaded without restarting Claude Desktop.

## 0.0.9 – 2026-11-20

- `render_preview` uses `Document.Export` with named export options (works with CorelDRAW 2026,
  where `ExportBitmap` has a different parameter list).
- `corel_status` reports the plain version number and the license / unofficial-project notice.

## 0.0.8 – 2026-11-20

- Registration also finds the Claude Desktop configuration of current Microsoft Store builds
  (`%LOCALAPPDATA%\Claude-Data\<package>\claude_desktop_config.json`).

## 0.0.7 – 2026-11-20

First public preview (proof of concept).

- MCP server for CorelDRAW on Windows, written in Go with no external dependencies (own MCP and COM layers).
- Tools: `corel_status`, `corel_launch`, `list_shapes`, `render_preview`, `create_rectangle`, `undo`, `redo`.
- Millimetres and page coordinates with origin at the top-left corner (Y down); every tool call is one undo step.
- Connects to a running CorelDRAW even when it is not registered in the Running Object Table (CorelDRAW 2026).
- Double-click the exe for a window that registers / unregisters LeoDraw in Claude Desktop (a backup of the
  configuration is made); also `--install` / `--uninstall`.
- Czech and English, light and dark theme.
